# Data

이 폴더에는 데이터 파일을 두지만, **데이터 자체는 git에 커밋하지 않습니다**
(`.gitignore`에서 제외됨). 대신 이 README에 데이터 출처와 받는 방법을 기록하세요.

## 데이터 출처 기록

새 데이터를 추가할 때마다 아래 표에 항목을 추가하세요.

| 데이터셋 | 위치(경로/URL) | 받는 방법 | 라이선스 | 추가 일자 |
|---|---|---|---|---|
| (예) Sample-X | `data/sample_x/` | `s3://bucket/...` 또는 `wget ...` | CC-BY-4.0 | 2026-MM-DD |

## 권장 하위 구조 (필요 시)

프로젝트 규모가 커지면 다음 같은 분리도 고려:

- `raw/` — 원본, 절대 수정 금지
- `interim/` — 중간 처리물
- `processed/` — 학습/평가용 최종
- `external/` — 외부 출처 보조 데이터

작은 프로젝트는 `data/` 하나로 충분합니다.

## 주의

- 원본은 절대 수정/덮어쓰기 금지.
- 개인정보(PII)가 포함된 경우 마스킹/익명화 후 저장.
- 큰 파일(수 GB 이상)은 별도 스토리지(S3, GCS 등) 사용을 권장.
