## TODO 1. 학습 yaml 작성

[`../configs/default.yaml`](../configs/default.yaml) 가 베이스. 복사 후 변경점만 수정.

```bash
cp configs/default.yaml configs/<exp>.yaml
```

핵심 키:

```yaml
experiment:
  name: 20260526_whisper_small_lr1e5   # outputs/<name>/ 폴더로 저장
  seed: 42

model:
  type: whisper                        # whisper | sensevoice
  backbone: openai/whisper-small       # HF ID 또는 로컬 백본 경로

data:
  text_field: text_normalized          # 평가와 일관

training:
  epochs: 5
  batch_size: 8                        # GPU 메모리에 맞춰
  lr: 1.0e-5
  precision: bf16                      # fp32 | fp16 | bf16
```

> 상단 주석에 **이번 실험에서 무엇을 왜 바꿨는지** 한 문장 박기 (미래에 결과 비교할 때 필수).

## TODO 4. 학습된 모델로 1번 벤치마크에 평가

학습이 끝나면 `outputs/<exp>/` 에 모델이 저장됨. **[1번](1_벤치마크구축.md) 의 평가 yaml 의 `model_path` 만 변경** 하면 끝.

```yaml
# BENCHMARK/configs/eval/whisper_finetuned_v1.yaml
recognizer:
  name: whisper_finetuned_v1           # ← 새 이름 (results 폴더 분리)
  type: whisper
  model_path: outputs/<exp>/model.pt.best   # ← 백본 경로 → 학습 체크포인트로 변경
  backbone: openai/whisper-small       # processor 는 그대로

  options:
    language: ko
    task: transcribe
    beam_size: 5
    batch_size: 16
    device: cuda:0

benchmarks:
  - Sample10_PracticeRef
  - <다른 bench_id>

batch_size: 16
```

실행은 [1번 TODO 4 Python 코드](1_벤치마크구축.md#todo-4-평가-실행-python-셀) 그대로 — yaml 경로만 새 yaml 로.

→ 결과는 `BENCHMARK/results/whisper_finetuned_v1/` 에 생김. 백본 결과(`baseline_whisper_small/`) 와 *나란히 비교* 가능.

## 막힘 핸들

| 증상 | 1차 조치 |
|---|---|
| CUDA OOM | `training.batch_size` ↓ → 그래도 안 되면 `grad_accum_steps` ↑, `precision: bf16` |
| 학습 너무 느림 | data loader `num_workers` ↑, SSD 사용, `precision: bf16` |
| 중간에 멈춤 (재개) | `training.resume_from: <checkpoint path>` 로 재개 |
| W&B 안 됨 | `WANDB_API_KEY` 환경변수 확인, `wandb login` |
| `train.jsonl` / `val.jsonl` 없음 | 학습 데이터 별도 작업 — 본 가이드 범위 밖. 데이터팀 확인 |
