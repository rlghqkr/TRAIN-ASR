# 3. 도메인 적응 실험 (공통)

특정 화자군·녹음환경에 모델을 **적응(어댑테이션)** 시키는 실험 묶음.
[2_모델학습](2_모델학습.md) 의 파인튜닝을 그대로 쓰되, **학습 데이터를 타깃 도메인 쪽으로 기울인다**.

| 실험 | 타깃 | 가이드 |
|---|---|---|
| 고령 화자 적응 | 60세 이상 발화 | [3_도메인적응_노인발화.md](3_도메인적응_노인발화.md) |
| 저음질 전화망 적응 | 8kHz 전화채널 발화 | [3_도메인적응_저음질전화망.md](3_도메인적응_저음질전화망.md) |

> 본 문서는 *개요* 만 다룬다 (필터·믹스 등 상세는 학습 데이터 준비 단계에서).

---

## 실험 구도 — 베이스라인 vs 특화

같은 조건에서 **타깃 도메인 데이터만 더했을 때**의 효과를 보는 통제 비교다.

| 모델 | 학습 데이터 | 역할 |
|---|---|---|
| **베이스라인** | KsponSpeech (일반 한국어) | 일반 기준선 |
| **특화(적응)** | KsponSpeech **+@** (타깃 도메인) | 타깃에 맞춤 |

- 두 모델을 **동일한 GOLD 벤치마크 전체**에 평가해 나란히 비교한다.
- 통제변수 = **+@(타깃 데이터) 뿐**. 그래야 개선이 도메인 데이터 덕분임이 분명해진다.
- KsponSpeech 가 일반 앵커라, +@ 만 추가해도 일반 성능이 잘 무너지지 않는다(리허설 효과).

---

## 핵심 원칙 — "타깃은 올리되 나머지는 떨구지 않는다"

적응의 성공 조건은 **타깃 CER ↓ AND 다른 벤치마크 CER 유지**다.
파인튜닝이 일반 능력을 깎으면(catastrophic forgetting) 실패다. 베이스라인 대비:

- **타깃 벤치마크**: 특화 모델이 좋아져야 함.
- **나머지 벤치마크**(Zeroth, KsponSpeech_Clean, KorLecture, FreeDialog_Child 등): 나빠지면 회귀.
- KsponSpeech 일반 앵커(+@ 구도)가 이 회귀를 막는 핵심 장치.

---

## 평가 (2번과 동일)

- 평가 방법·산출물은 [1_벤치마크구축](1_벤치마크구축.md) / [2_모델학습](2_모델학습.md) 그대로.
- **평가셋은 GOLD 벤치마크 전체를 동일하게 쓴다.** 베이스라인·특화 둘 다 같은 벤치에 평가.
- **베이스라인(KsponSpeech) 모델과 특화(KsponSpeech+@) 모델을 *나란히* 비교** (벤치마크별 CER 표).

---

## 모델 사이즈

`/data/FM/MODEL/whisper/` 의 `tiny · base · small · medium · large-v3` 중:

- **주력 = whisper-small.** 파인튜닝이 빠르고 합리적 성능 → 믹스 비율·LR 등 레시피는 여기서 확정.
- **확정 후 medium 1회 재확인** (production 후보).
- large-v3 는 비용 크고 망각 위험 ↑ → 보통 과함. tiny/base 는 베이스라인 곡선 관찰용.

> 먼저 5개 사이즈 zero-shot 베이스라인을 떠서 출발 CER 곡선을 보면, 용량 문제인지 도메인 문제인지 판별된다.

## 학습 실행

[2_모델학습_whisper.md](2_모델학습_whisper.md) 그대로. config 만 실험용으로 복사해 쓴다.

```bash
# 학습용 config 예시 (이미 추가됨): configs/whisper_senior_adapt_v1.yaml 등
scripts/train.sh configs/<exp>.yaml whisper

# 학습 직후 자동 평가 (GOLD 벤치마크 yaml 지정)
EVAL_CONFIG=BENCHMARK/configs/<exp>_eval.yaml scripts/train.sh configs/<exp>.yaml whisper
```

- 학습/검증 JSONL(`paths.train_jsonl`/`val_jsonl`)은 **전처리 산출물 경로만** 넣는다.
- ⚠ 학습 데이터는 **전처리 진행 중** — 경로가 아직 없을 수 있다. 준비된 코퍼스부터 시작하면 된다.

---

## 자주 만나는 함정

- **타깃 데이터만으로 학습** → 일반 벤치마크 회귀. KsponSpeech 같은 일반 데이터를 함께 학습(= 특화는 KsponSpeech+@).
- **타깃 벤치마크만 평가** → 회귀를 놓침. GOLD 전체(가드 포함)로 평가.
- **학습/평가 누수** — 같은 음원이 학습·평가 양쪽이면 평가 무의미. (전처리 단계에서 벤치마크 음원 배제)
